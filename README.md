# Saavedrismo · instrumentos y plugins gratis

Web: **https://nikokubrick.github.io/saavedrismo/**

Instrumentos y plugins de audio hechos por Nico Saavedra ([nicosaavedra.tech](https://nicosaavedra.tech)):

- **Lirio**: máquina de acordes (Windows y Mac; VST3, AU y programa). Software libre, GPLv3.
- **Niebla Studio**: sintetizador ambiental (Windows y Mac).
- **Bowery NY Crush**, **Desarmador**, **Hurlingham 810** y **Latex Board**: efectos VST3 para Windows.

Las descargas están en la sección *Releases* (`descargas`). La rama `archivos` guarda los archivos que se publican ahí.
